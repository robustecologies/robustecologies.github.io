# Enrich the species table with class/order/family from the taxonomy cache

Maintainer-side helper. Merges the offline GBIF backbone resolution
cached in the private ingestion tree into the compilation species table,
populating the `class`, `order`, `family` and `is_vertebrate` columns.
The cache is regenerated by a maintainer script that calls the GBIF
backbone API; the cached TSV is never user-facing.

## Usage

``` r
enrich_taxonomy(spp, data_raw = NULL)
```

## Arguments

- spp:

  `data.table` of species with at least a `species_id` column.

- data_raw:

  Path to a maintainer-side ingestion tree. Absent in the installed
  package; the function aborts when the directory does not exist.

## Value

The species table augmented with backbone columns. Species absent from
the cache are left with `NA` in those fields.

## Details

If the taxonomy cache is missing inside an otherwise-valid ingestion
tree, the function is a no-op and returns the input unchanged. The
resolution is offline and uses a TSV the maintainer regenerates after
compilation changes; the regeneration script lives in the private
ingestion tree and is not shipped.
