# Compute normalized solid angle measure in R^2

Computes the normalized solid (plane) angle measure of a cone in R^2
generated by two unit vectors. The normalized measure is the fraction of
the plane occupied by the cone.

## Usage

``` r
solid_angle_2d(v1, v2)
```

## Arguments

- v1:

  First unit vector (length 2)

- v2:

  Second unit vector (length 2)

## Value

The normalized solid angle measure (a number between 0 and 1)

## Details

In R^2, the solid angle is the *smaller* angle between the two rays
divided by \\2\pi\\. For a simplicial cone (nonnegative combinations),
opposite or colinear generators define a lower-dimensional cone and
therefore have solid angle 0.

## Examples

``` r
# Right angle (quarter plane)
v1 <- c(1, 0)
v2 <- c(0, 1)
solid_angle_2d(v1, v2)  # Should be 0.25
#> [1] 0.25

# 45 degree angle
v1 <- c(1, 0)
v2 <- c(1, 1) / sqrt(2)
solid_angle_2d(v1, v2)  # Should be 0.125 (45/360)
#> [1] 0.125

# Opposite rays (degenerate cone -> 0)
v1 <- c(1, 0)
v2 <- c(-1, 0)
solid_angle_2d(v1, v2)  # Should be 0
#> [1] 0
```
