# Demon FX data set

This data set consists of daily currency pair prices from 2010 through
2014. Each currency pair has a close, high, and low price for 13 pairs
(39 columns total).

## Format

A data frame with 1301 rows (trading days) and 39 columns of currency
pair prices: EURUSD, USDJPY, USDCHF, GBPUSD, USDCAD, EURGBP, EURJPY,
EURCHF, AUDUSD, GBPJPY, CHFJPY, GBPCHF, and NZDUSD, each with Close,
High, and Low values.
