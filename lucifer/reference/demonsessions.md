# Demon sessions data set

Monthly number of user sessions at bayesian-inference.com by continent.

## Format

A data frame with 26 rows (months) and 6 columns:

- Africa:

  Sessions from the African continent.

- Americas:

  Sessions from North and South America.

- Asia:

  Sessions from the Asian continent.

- Europe:

  Sessions from Europe.

- Oceania:

  Sessions from Oceania (e.g. Australia).

- Not.Set:

  Sessions where the continent was not set or unknown.
