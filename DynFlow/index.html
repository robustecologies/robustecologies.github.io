RElabFlow studio

Choose a model from the library or write your own, perturb it, choose a view and a style, and export the result as an image, a film, a standalone page or a live element for web pages and slides. Every scene is a small JSON file that holds its own equations, so it can be reopened here or played anywhere with relabflow.js.

Keys

Space play or pause, R restart, S one frame, N new random seed, F full screen, P save a PNG, Esc close. On the figure, a click seeds orbits in 2D views and a drag rotates 3D views.

Formula language

# differential equations (x' or dx/dt), maps (x[n+1]), noise and delays
x' = a*x - b*x*y              y[n+1] = r*y*(1 - y)
noise x = sigma*x             # Ito diffusion coefficient of dW_x
z' = -z + lag(x, tau)         # delayed state x(t - tau)
aux f = x/(1 + x)             # helper used by the equations
param a = 1 [0, 3]            # value and slider range
init x = 0.5
range x = [0, 4]              # axis range

Functions: sin cos tan exp log sqrt abs min max pow mod step ifelse clamp hill tanh atan2 and others; t is time (or the step for maps); pi, e. Random draws urand() and nrand() are fresh for every member of the ensemble; ucommon(k) and ncommon(k) are shared by the whole ensemble at each step, which turns a map into a random dynamical system.

Playback

A figure plays a fixed amount of model time per second of real time. RElabFlow measures that rate for each model and view, so that a trajectory crosses about one plot width per second, a time series scrolls one window in 10 s and a sweep crosses its interval in 25 s. The Speed control multiplies the rate. Set a rate of your own under Model, Integration; Auto measures it again. When the computer cannot keep up, the readout shows the fraction of real time that the figure keeps.

Numerics

Differential equations use the classical fourth-order Runge-Kutta scheme at a fixed step; stochastic equations the Euler-Maruyama scheme (Ito); delay equations Runge-Kutta 4 with a cubic Hermite interpolant of the history, constant before the start. Equilibria are found by damped Newton iteration and classified by the eigenvalues of the Jacobian. The sweep view follows each branch of equilibria by pseudo-arclength continuation, through its folds, and marks folds, Hopf points and branch points. The test files in tests/ check the schemes and the catalogue against closed forms and published values.

Using a scene elsewhere

<script src="relabflow.js"></script>
<relab-flow src="lorenz.json" controls style="height:420px"></relab-flow>
<relab-flow model="may-leonard" theme="blackboard"></relab-flow>

In R Markdown, Quarto and pkgdown, emit the same two tags with htmltools. In reveal.js, place the element in a slide or use the standalone page in an iframe. The element starts when it becomes visible and shows a still frame when the reader prefers reduced motion.
