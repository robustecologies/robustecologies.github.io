# Colored (1/f^beta) noise specification

Creates a noise specification for driving an SDE with spectrally colored
noise. The power spectral density scales as S(f) ~ 1/f^beta, where
beta=0 gives white noise, beta=1 gives pink (1/f) noise, and beta=2
gives red (Brownian) noise.

## Usage

``` r
colored_noise(beta = 1, amplitude = 1)
```

## Arguments

- beta:

  Spectral exponent (default: 1.0). Must be non-negative. beta=0 is
  white, beta=1 is pink, beta=2 is red/Brownian.

- amplitude:

  Noise amplitude scaling factor (default: 1.0).

## Value

An S3 object of class `noise_spec` with `type = "colored"`.

## Details

Colored noise is generated by spectral synthesis: random phases are
assigned to frequency components whose amplitudes are scaled by
f^(-beta/2), and the inverse FFT produces a time series with the desired
spectral slope. The resulting noise is normalized to zero mean and unit
variance, then scaled by the amplitude parameter.

The noise vector is pre-generated in R using base R
[`fft()`](https://rdrr.io/r/stats/fft.html) and passed to the C++
integrator. This avoids the need for FFT routines in C++.

Colored noise is standalone: it cannot be composed with Levy,
correlated, or fBm noise. Only Euler-Maruyama is valid (Milstein is
blocked).

## References

Timmer, J. & Koenig, M. (1995). On generating power law noise.
*Astronomy and Astrophysics*, 300, 707-710.

## Examples

``` r
if (FALSE) { # \dontrun{
model <- model_spec(
    rhs = list(x ~ -theta * x),
    diffusion = list(x ~ sigma),
    noise = colored_noise(beta = 1.0),
    state_names = "x",
    parms = list(theta = 1, sigma = 0.3),
    init = c(x = 0)
)
result <- dyn_sim(model, t_max = 50,
                  solver = solver_euler_maruyama(dt = 0.01))
print(result)
plot(result)
} # }
```
