# Plot method for slow_fast_partition

Default plot: spectrum of Jacobian eigenvalues with fast and slow blocks
coloured separately.

## Usage

``` r
# S3 method for class 'slow_fast_partition'
plot(x, ...)
```

## Arguments

- x:

  A `slow_fast_partition` object.

- ...:

  Unused.

## Value

Invisibly returns the ggplot object.
