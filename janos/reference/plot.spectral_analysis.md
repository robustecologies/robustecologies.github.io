# Plot method for spectral_analysis objects

Plot method for spectral_analysis objects

``` r
# S3 method for class 'spectral_analysis'
plot(x, type = c("spectrum", "combined"), ...)
```

## Arguments

- x:

  A `spectral_analysis` object

- type:

  Type of plot: "spectrum" (default) or "combined"

- ...:

  Additional arguments (ignored)
