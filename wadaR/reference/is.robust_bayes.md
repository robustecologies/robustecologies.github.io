# Test for class robust_bayes

Tests whether an object is of class `robust_bayes`.

## Usage

``` r
is.robust_bayes(x)
```

## Arguments

- x:

  An object to test.

## Value

Logical; `TRUE` if `x` inherits from `robust_bayes`.
