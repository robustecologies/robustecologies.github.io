# wadaR: Wada basin detection in dynamical systems

Implements multiple methods for detecting Wada basins of attraction in
dynamical systems. Wada basins are a special type of fractal basins
where a single boundary separates three or more basins. The package
provides four detection methods: the grid method (Daza et al., 2015),
the merging method (Daza et al., 2018), the saddle-straddle method
(Wagemakers et al., 2020), and theoretical support for the classical
Nusse-Yorke method. High-performance Rcpp implementations are provided
for computationally intensive operations.
