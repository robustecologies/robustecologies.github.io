# wadaR: Wada basins of attraction and bifurcations in chaotic dynamical systems

Implements multiple methods for detecting Wada basins of attraction in
chaotic dynamical systems. Wada basins are a special type of fractal
basins where a single boundary separates three or more basins. The
package provides four detection methods: the grid method , the merging
method, the saddle-straddle method, and theoretical support for the
classical Nusse-Yorke method. Streamlined with high-performance
parallelized Rcpp/OpenMP implementations.
