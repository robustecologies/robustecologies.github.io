# Plot method for density_landscape_2d objects

Plot method for density_landscape_2d objects

## Usage

``` r
# S3 method for class 'density_landscape_2d'
plot(x, type = c("density", "surface"), title = NULL, ...)
```

## Arguments

- x:

  A `density_landscape_2d` object.

- type:

  Character; `"density"` (default) for filled contour, or `"surface"`
  for 3D plotly surface.

- title:

  Optional plot title.

- ...:

  Additional arguments (ignored).

## Value

A ggplot2 or plotly object.
