# Summary method for merged_basins objects

Provides extended statistics including area ratios and boundary analysis
for merged basin configurations.

## Usage

``` r
# S3 method for class 'merged_basins'
summary(object, ...)
```

## Arguments

- object:

  A merged_basins object.

- ...:

  Additional arguments (ignored).

## Value

A summary.merged_basins object (invisibly).
