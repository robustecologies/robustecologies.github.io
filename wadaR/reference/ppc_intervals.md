# PPC credible intervals

Convenience wrapper for PPC interval plots.

## Usage

``` r
ppc_intervals(x, ...)
```

## Arguments

- x:

  A PPC object.

- ...:

  Additional arguments passed to `.plot_ppc`.

## Value

Invisibly returns the plot object.

## Details

Implementation of `ppc_intervals`. Refer to the package vignettes and
the cited references for a complete algorithmic and mathematical
description.
