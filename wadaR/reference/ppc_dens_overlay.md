# PPC density overlay

Convenience wrapper for PPC density overlay plots.

## Usage

``` r
ppc_dens_overlay(x, ...)
```

## Arguments

- x:

  A PPC object (class `demonoid.ppc`, `laplace.ppc`, etc.).

- ...:

  Additional arguments passed to `.plot_ppc`.

## Value

Invisibly returns the plot object.

## Details

Implementation of `ppc_dens_overlay`. Refer to the package vignettes and
the cited references for a complete algorithmic and mathematical
description.
