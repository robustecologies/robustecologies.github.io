# RElab extended discrete color scale

See Details.

## Usage

``` r
scale_color_relab_d_extended(n, ...)
```

## Arguments

- n:

  Number of colors needed. Interpolates when `n > 10`.

- ...:

  Arguments passed to `scale_color_manual`.

## Value

A ggplot2 scale object.

## Details

Implementation of `scale_color_relab_d_extended`. Refer to the package
vignettes and the cited references for a complete algorithmic and
mathematical description.
