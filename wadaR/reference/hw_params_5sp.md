# Create parameters for 5-species competition scenario

Create parameters for 5-species competition scenario

## Usage

``` r
hw_params_5sp(dilution = 0.25, supply = c(10, 10, 10))
```

## Arguments

- dilution:

  Dilution rate D (default 0.25).

- supply:

  Supply concentrations (default c(10, 10, 10)).

## Value

List of model parameters.
