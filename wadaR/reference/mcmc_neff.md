# MCMC ESS ratio plot

Convenience wrapper for `plot(x, type = "neff", ...)`.

## Usage

``` r
mcmc_neff(x, ...)
```

## Arguments

- x:

  An object of class `demonoid`.

- ...:

  Additional arguments passed to `plot.demonoid`.

## Value

Invisibly returns the plot object(s).

## Details

Implementation of `mcmc_neff`. Refer to the package vignettes and the
cited references for a complete algorithmic and mathematical
description.
