# Plot method for von Karman peak extraction

Renders the extracted peaks against the underlying time series. The plot
carries the canonical subtitle and grey caption used elsewhere in the
package.

## Usage

``` r
# S3 method for class 'vonkarman_peaks'
plot(x, ...)
```

## Arguments

- x:

  A `vonkarman_peaks` object.

- ...:

  Ignored.

## Value

A ggplot2 object.
