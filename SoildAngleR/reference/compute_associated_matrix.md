# Compute the associated matrix of a simplicial cone

Constructs the associated matrix M_n(C) for a simplicial cone C
generated by unit vectors v1, ..., vn. The matrix has 1's on the
diagonal and \\-\|v_i \cdot v_j\|\\ for off-diagonal entries (Definition
1.4).

## Usage

``` r
compute_associated_matrix(V)
```

## Arguments

- V:

  An n x n matrix where columns are the unit vectors generating the cone

## Value

An n x n symmetric matrix

## Details

The associated matrix is used to determine convergence of the
hypergeometric series formula (Theorem 1.5). The series converges if and
only if this matrix is positive definite.

## References

Fitisone, A., & Zhou, Y. (2023). Solid angle measure of polyhedral
cones. arXiv:2304.11102 (math.CO). <https://arxiv.org/abs/2304.11102>

Ribando, J. M. (2006). Measuring solid angles beyond dimension three.
*Discrete & Computational Geometry*, 36(3), 479-487.
[doi:10.1007/s00454-006-1253-4](https://doi.org/10.1007/s00454-006-1253-4)

## Examples

``` r
# 2D example
v1 <- c(1, 0) / sqrt(1)
v2 <- c(1, 1) / sqrt(2)
V <- cbind(v1, v2)
M <- compute_associated_matrix(V)
print(M)
#>            [,1]       [,2]
#> [1,]  1.0000000 -0.7071068
#> [2,] -0.7071068  1.0000000

# Check positive definiteness
eigen(M)$values  # All positive
#> [1] 1.7071068 0.2928932
```
