# Hypergeometric series for n=2 (specialized implementation)

Specialized implementation for 2D cones.

## Usage

``` r
hypergeometric_series_2d(V, max_terms, tol)
```

## Arguments

- V:

  2 x 2 matrix of unit vectors

- max_terms:

  Maximum terms

- tol:

  Tolerance

## Value

List with results
