# Cross product of two 3D vectors

Computes the cross product of two 3-dimensional vectors.

## Usage

``` r
cross_product_3d(a, b)
```

## Arguments

- a:

  First 3D vector

- b:

  Second 3D vector

## Value

Cross product vector \\a \times b\\

## Examples

``` r
a <- c(1, 0, 0)
b <- c(0, 1, 0)
cross_product_3d(a, b)  # c(0, 0, 1)
#> [1] 0 0 1
```
