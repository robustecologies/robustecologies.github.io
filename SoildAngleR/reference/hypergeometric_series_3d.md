# Hypergeometric series for n=3 (specialized implementation)

Specialized implementation for 3D cones using equation (5).

## Usage

``` r
hypergeometric_series_3d(V, max_terms, tol)
```

## Arguments

- V:

  3 x 3 matrix of unit vectors

- max_terms:

  Maximum terms

- tol:

  Tolerance

## Value

List with results
