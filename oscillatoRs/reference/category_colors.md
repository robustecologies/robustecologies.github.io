# Category color palette

Returns a named vector of colors for climate index categories.

## Usage

``` r
category_colors()
```

## Value

Named character vector of hex colors.

## References

Wilke, C. O. (2019). *Fundamentals of data visualization*. O'Reilly
Media. ISBN 978-1492031086

## Examples

``` r
category_colors()
#>                 ENSO       Teleconnection             Atlantic 
#>            "#E41A1C"            "#377EB8"            "#4DAF4A" 
#> Pacific multidecadal          Pacific SST                Polar 
#>            "#984EA3"            "#FF7F00"            "#00CED1" 
#>         Indian Ocean          Atmospheric        Precipitation 
#>            "#A65628"            "#F781BF"            "#999999" 
#>                Solar          Temperature 
#>            "#FFD700"            "#8B0000" 
```
