# Print the dispositions of buddhi

Print the dispositions of buddhi

## Usage

``` r
# S3 method for class 'samkhya_bhava'
print(x, ...)
```

## Arguments

- x:

  An object of class `samkhya_bhava`.

- ...:

  Further arguments, ignored.

## Value

`x`, invisibly.

## See also

[`buddhi_bhavas()`](https://robustecologies.github.io/SamkhyaR/reference/buddhi_bhavas.md).
