# Print method for chameleon_surrogates objects

One-screen summary of a surrogate ensemble produced by
[`generate_surrogates`](https://robustecologies.github.io/chamaeleon/reference/generate_surrogates.md).
Reports the surrogate-generation method, the number of surrogate
realisations, the type of input the ensemble was built from, and the
dimensionality of a single surrogate.

## Usage

``` r
# S3 method for class 'chameleon_surrogates'
print(x, ...)
```

## Arguments

- x:

  Object of class `chameleon_surrogates`.

- ...:

  Additional arguments (ignored).

## Value

The input `x`, returned invisibly.
