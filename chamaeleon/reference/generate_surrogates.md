# Plot method for chameleon_surrogates objects

Visualize surrogate distributions generated by `generate_surrogates`.
For time-series surrogates, overlays density curves of individual
surrogates against the original series. For scale-metrics surrogates,
plots the surrogate envelope (5th-95th percentile) alongside the
observed scale-dependent metrics.

Generate surrogate realizations of scale-dependent metrics or time
series under specified null hypotheses. Multiple methods are available
to preserve different properties of the original data.

## Usage

``` r
# S3 method for class 'chameleon_surrogates'
plot(x, ...)

generate_surrogates(
  x,
  n_surrogates = 199,
  method = c("scale_shuffle", "fourier", "iaaft", "block_bootstrap"),
  block_length = NULL,
  ...
)
```

## Arguments

- x:

  Object of class `scale_metrics`, object of class `chameleon_analysis`,
  numeric matrix of D and theta values by scale, or numeric vector (time
  series). When `method = "scale_shuffle"` and `x` is a numeric vector
  or a `chameleon_analysis` object, the scale-resolved metrics are
  extracted internally via
  [`chameleon_analysis`](https://robustecologies.github.io/chamaeleon/reference/chameleon_analysis.md),
  mirroring
  [`chameleon_test`](https://robustecologies.github.io/chamaeleon/reference/chameleon_test.md).

- ...:

  Additional arguments forwarded to
  [`chameleon_analysis`](https://robustecologies.github.io/chamaeleon/reference/chameleon_analysis.md)
  when scale-resolved metrics must be computed from a raw time series
  under `method = "scale_shuffle"`.

- n_surrogates:

  Integer. Number of surrogates to generate (default 199).

- method:

  Character. Surrogate generation method (see Details).

- block_length:

  Integer. Block length for block bootstrap (default is automatically
  determined as n^(1/3)).

## Value

A patchwork ggplot2 composition, returned invisibly.

Object of class `"chameleon_surrogates"`: a list of surrogate
realizations, each having the same structure as the input. Attributes
`method`, `n`, and `input_type` record the generation parameters. A
`plot.chameleon_surrogates` method is available.

## Details

The surrogate distribution provides the null distribution for the
chameleon test. For series-type surrogates, each density curve
represents one realization of the null model; for scale-metrics
surrogates, the ribbon spans the 5th-95th percentile of the null
distribution across surrogates.

**Available methods:**

- "scale_shuffle":

  Randomly permute the frequency labels of the computed D(f) and
  theta(f) metrics. This directly tests whether metrics depend on scale
  by breaking the scale ordering while preserving the marginal
  distributions of the metrics. Primary method for testing H0.

- "fourier":

  Phase randomization via FFT. Preserves the power spectrum (linear
  autocorrelation structure) but destroys phase relationships and
  nonlinear structure. Tests whether observed patterns could arise from
  a linear Gaussian process.

- "iaaft":

  Iterative Amplitude Adjusted Fourier Transform. Preserves both the
  power spectrum and the amplitude distribution (histogram) of the
  original signal. More appropriate than Fourier surrogates for
  non-Gaussian data. Tests the null of a monotonic nonlinear
  transformation of a linear Gaussian process.

- "block_bootstrap":

  Circular block bootstrap. Preserves local temporal structure within
  blocks while destroying long-range dependence. Useful when local
  dynamics should be preserved but long-range correlations tested.

## Examples

``` r
if (FALSE) { # \dontrun{
set.seed(42)
x <- sin(seq(0, 20 * pi, length.out = 2000)) + 0.1 * rnorm(2000)
surr <- generate_surrogates(x, n_surrogates = 19)
plot(surr)
} # }

if (FALSE) { # \dontrun{
# Generate scale-shuffle surrogates from a precomputed scale_metrics object
surrogates <- generate_surrogates(scale_metrics_obj, n_surrogates = 99)

# Generate scale-shuffle surrogates directly from a time series
# (scale_metrics is computed internally via chameleon_analysis)
surrogates <- generate_surrogates(time_series, n_surrogates = 99)

# Generate IAAFT surrogates from time series
surrogates <- generate_surrogates(time_series, method = "iaaft")
} # }
```
